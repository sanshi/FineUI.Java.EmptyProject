标签式声明

一个标签一个控件，一个属性一个功能，所写即所得——页面结构一眼可读、可维护。

🔄

状态自动往返

控件状态在前后端之间自动保持——后端直接读写控件属性、事件直达处理方法，像写桌面程序一样写 Web。

🤖

AI 友好

所有控件都遵循同一套声明式标签规范——AI 好生成，人也看得懂。

☕

Spring Boot 全栈

一个依赖即可接入，不碰 JavaScript、无需前后端分离；控件状态不绑定单台服务器，天然支持水平扩展。

— 页面写标签，后端写事件方法 —
<!-- 页面：一个标签一个控件 -->
<f:simple-form>
    <f:text-box id="tbxUser" label="用户名"/>
    <f:button id="btnLogin" text="登录" on-click="btnLogin_Click"/>
    <f:label id="lblHi"/>
</f:simple-form>

// 后端：事件里直接读写控件状态，自动同步到前端
public void btnLogin_Click(Object sender, EventArgs e) {
    String user = tbxUser.getText();        // 读控件状态
    lblHi.setText("你好，" + user);   // 写控件状态 → 自动回传前端
}
状态自动往返、事件直达后端——不写一行 JavaScript。
